## Why

客户月度考勤明细要以 `工作簿11111.xlsx` 的格子语义为准：有卡显示时间，有假显示假别，有加班单才涂加班色，半天上下两段可以不同。当前正式矩阵只把打卡时间放进格子、整格抢一个状态色，请假/加班/补签/陪产假等在主表几乎看不见，半天假更无法分色。

## What Changes

- 报表中心「月度考勤明细矩阵」按客户样表重写日期格文案和颜色，一人一行，不上「签到/签退」列，外框仍是一个日期单元格。
- 每个日期格拆成上下两段（上班段 / 下班段）：假别、漏刷、补签、迟到、早退、时间各自写在对应半格，半格独立上色。
- 全天同一状态（年假、出差、陪产假等）合并为居中一个字，不再写两行相同假别；跨天假每天一格，不跨列合并。
- 图例色覆盖迟到、早退、漏刷、加班、调休、外出、出差、事假、病假、年假、休息日、补签；陪产假、婚假、丧假、产假、工伤假等其它假别必须出字，可以不上色。
- 主表假别不写小时；悬停展示上午半天 3.5 小时、下午半天 4.5 小时（本次写死）。加班必须有已生效 OA 加班单才涂绿，格子保留时间，加班说明进悬停。
- 后端月矩阵日格从「整日徽章」改为按上午段/下午段覆盖；OA 请假半天用单据起止时间，全天/多天为连续不断开区间。
- 不引入驻外、不打卡、离职、入职、停职留薪等格子文案。漏刷仍写「漏刷」。

## Capabilities

### New Capabilities

- `month-matrix-cell-display`: 月度考勤明细矩阵日期格的分段文案、颜色、全天合并、悬停内容和 OA 半天/全天覆盖规则。

### Modified Capabilities

无。主 `openspec/specs/` 尚无已发布的矩阵展示规格；本次新增能力，不改其它已归档能力的需求句。

## Impact

- 后端 `AttendanceMonthMatrixAssembler` / `AttendanceMonthMatrixPage.DayCell` / 月矩阵 REST 响应：日格需携带上下段文案、色码、悬停材料和假别小时，而不能只给 `firstPunchAt` / `lastPunchAt` / `badges`。
- 前端报表中心 `toAttendanceDetailRows`、`AttendanceMatrixRow`、`customerReports.css`：一格两段独立绘制，全天合并居中；演示数据 `applyAttendanceStatus` 与正式映射对齐。
- Wave7 `ReportsPage` 正式月矩阵若仍读同一 API，需兼容新字段或继续用旧字段；默认不把 Wave7 页改成客户样表样式，除非新字段可向后兼容。
- 导出 Excel 若复用同一行映射，应跟页面格子语义一致；不在本次改其它报表页（请假统计、加班汇总、出勤率等）。
- 不改出勤计算引擎、OA 同步、加班认定公式；只消费已有日事实和 OA 单据区间。
