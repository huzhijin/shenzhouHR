## Why

白天正常上下班、晚上再来、次日上班前离开（含连续多日）时，报表用首卡末卡和 `HH:mm` 显示凌晨离开，像当天下午或次日上班；加班小时按零点切开后次日多出一截；班后有卡无单时异常总览常常是空的。人事已确认按建议口径改展示和异常。现场对照人：王凯祥 `SZST0431` 2026-08-05/06/07，金玉亮 `SZST0398` 2026-08-10 与 08-11 跨到次日凌晨。

## What Changes

- 过夜离开卡切点改为**次日该员工已发布班次上班点**，不再用 06:00。
- 月矩阵、考勤日报、个人页：跨日离开写成 `次日 HH:mm`，记在加班开始日；次日早上格只用次日上班卡。
- 考勤日报 / 月矩阵 / 加班日报：过夜单小时整段记在开始日；财务加班表仍按上海日历零点切开。
- 班后或过夜离开有卡、没有盖住该段的有效加班单 → 异常总览 **未报加班**（不挡月结，小时为 0）。
- 有有效加班单则不因「加过夜」再出异常；当天首卡到末卡 ≥ 14 小时另出 **长时在岗待审**（不挡月结，人事可取消）。
- 中间卡（下班回家、晚上回来）不算缺卡；有则写进日报备注。
- **不做**纸质加班（入口已隐藏）；不改 OA 插件填单；不引入夜班班次。

## Capabilities

### New Capabilities

- `overnight-clock-display`: 过夜切点、次日时刻文案、次日早上格不显示离开卡
- `overnight-overtime-start-day`: 人看的表按开始日记加班小时；财务加班按日历日切
- `undeclared-off-schedule-overtime`: 有班后/过夜卡无盖住的加班单 → 未报加班
- `long-punch-span-review`: 首卡到末卡 ≥ 14 小时 → 长时在岗待审
