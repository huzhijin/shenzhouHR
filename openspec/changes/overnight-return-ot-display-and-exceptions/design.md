## Context

过夜规格已要求切点是次日班次上班点、离开卡归前一天，但核算证据窗仍用 06:00 交接；展示一律 `HH:mm`。加班分钟按日历零点写入日事实，考勤日报和财务加班读同一列。异常总览 `ACTIONABLE` 不含 `OVERTIME_DOCUMENT_MISSING_OR_LATE`；该类型目前主要挂在「已有加班单但不及时」上，而不是「班后有卡无单」。

人事 2026-08-28 确认：打卡建议四次但不强制；一张跨夜单填真实加班区间；格子写 `次日 HH:mm`；人看的表小时记开始日、财务仍切零点；无单要未报加班；有单不加「跨夜审核」；首末 ≥ 14h 要长时待审；中间卡不算缺卡。纸质加班入口已隐藏，本次不改。过夜 = 次日上班之前。

## Goals / Non-Goals

**Goals:**

- 过夜离开卡归属与展示与次日班次上班点一致。
- 人看的表（矩阵、考勤日报、加班日报）过夜小时在开始日；财务加班保持日历切。
- 无盖住的有效加班单 → 未报加班进总览；≥14h 长时待审；有单不因跨夜本身再出审核异常。
- 用王凯祥 8/5–7、金玉亮 8/10–12 做验收/golden。

**Non-Goals:**

- 不改纸质加班重叠/录入。
- 不改 OA 插件填单（插件已按班次上班点校验跨夜）。
- 不排夜班班次、不强制 17:30/21:00 两张中间卡、不强制过夜后休息。
- 不自动把未报加班算成小时。

## Decisions

### 1. Overnight cut is next published shift start

`overnightCut` / `selectDayClocks` 的次日交接从 06:00 改为次日最早已发布 WORK `segmentStart`（无班次时再退回 08:30）。`[D+1 00:00, shiftStart)` 的卡只挂在 D 的 `lastPunchAt`。

备选：继续 06:00。否决，人事明确次日上班之前。

### 2. Display formatter takes the business date

统一 `formatPunch(businessDate, instant)`：上海日历日晚于业务日则 `次日 HH:mm`。矩阵下午格、日报下班列、悬停、个人页共用。02:00 虽早于正午，只要日期是次日就走下班格 + `次日`，不要当成次日上班。

### 3. Keep calendar minutes on daily facts; fold at HR read path

日事实 `recognized/paid/compensatory/voluntary` **仍按日历零点切**（现有 `minutesByDay`），财务加班 SQL 不用改。

考勤日报、加班日报、月矩阵加班色/小时：对「开始日 D、结束在 D+1 且结束时刻 &lt; D+1 shiftStart」的有效加班单，把 D+1 那一截分钟加回 D、从 D+1 展示里去掉。矩阵不得只因 `00:00–shiftStart` 续加班把次日整格涂绿。

备选：日事实改成开始日、财务查询再切。否决，财务页和 pin 列会一起漂。

### 4. Undeclared overtime from punches vs covering form

在开始日：若末卡晚于当天班次下班，或末卡是过夜离开卡，且没有任何 **effective** 加班单盖住 `[shiftOff, lastPunch]`（过夜则到离开卡），则写 `OVERTIME_DOCUMENT_MISSING_OR_LATE`。小时仍为 0。总览 `ACTIONABLE` 加上该类型。有生效单盖住则不出。草稿/审批中不算生效（与现网加班小时同一套 effective 状态）。

不新造类型，避免查询映射再裂一条。中文标签：未报加班。

### 5. Long span is a new non-blocking type

`LONG_PUNCH_SPAN_REVIEW`：`Duration.between(first, last) >= 14h`。有加班单也不自动消失（防工牌放公司）。人事用已有「取消异常」清掉。总览白名单加上。不挡月结。

金玉亮 8/10 `08:26–19:01` 约 10.5h → 不出。8/11 `08:26`–次日 `00:14` 约 15.8h → 出。

### 6. Paper overtime and OA plugin out of scope

纸质加班隐藏，不改占用日历日逻辑。OA 插件已按班次上班点要离开卡；本次只改 HR 核算与报表。

### 7. Formula catalog bump

展示折叠和异常集合变化后，OPEN 月须重算。目录版本 +1（V6 → V7）。旧 pin 不混读。

## Risks / Trade-offs

- [Risk] 王凯祥 8/5–7 本地 dump 无 8 月卡 → 实现第一步从 HR 库/得力证据抽出真实卡和加班单再锁 golden；抽不到则用金玉亮 8/11–12 实卡 + 合成四卡用例。
- [Risk] 人事点名金玉亮 8/10–11，dump 里过夜离开在 8/12 00:14 → 规格以打卡时刻归属为准，8/10 当天 19:01 不当过夜。
- [Risk] 未报加班 + 长时待审同一天两行 → 一个要补单、一个要看 14h；接受噪音，避免漏忘打卡。
- [Risk] 次日 07:20 大连早到被当成过夜离开 → 沿用已有「`[00:00, shiftStart)` 归前一天」；大连到达窗早于上班点的争议不在本次重开。
- [Risk] 财务与日报同一人同一夜数字不同 → 页上财务加班保持日历切；日报备注可写「加班记开始日」。
