## 2. 查询不算账，缺数据给提示

- [x] 2.1 官方报表 GET、月矩阵、看板、新查询接口：没有 pin 时不在请求线程跑整月核算
- [x] 2.2 该月已有得力/OA 水位但还没有 pin：返回「核算尚未完成」（可重试），有 `REFRESH` 的人可点重新计算
- [x] 2.3 该月没有来源也没有 pin（例如只有 7、8 月打卡却查 6 月）：HTTP 成功、0 行，提示「该期间暂无打卡或核算数据」，不报错
- [x] 2.4 单据跨月查询：有 pin 的月份出数，缺数月份点名「未计入」，不把整段期间打成失败
- [x] 2.5 后台或手动重算进行中：查询继续返回旧 pin
- [x] 2.6 加载中禁用查询/刷新，禁止用全 0 和「暂无记录」冒充空数据

## 4. 九张查询接口

- [x] 4.3 加班：部门、工号、起止期间、计薪/调休/义务、发生日

- [x] 4.7 出勤率：部门、工号、类型或低于某比例
- [x] 4.8 年假：部门、工号、余额档、一/二级部门
- [x] 4.9 考勤明细：部门、工号、考勤状态、当月日期；按员工分页，禁止一次返回整月 560×31
