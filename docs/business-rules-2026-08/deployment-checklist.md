## 4. 配置并启用得力整点同步

应用默认关闭自动同步。只有来源凭据、员工绑定、公司/部门路由和对账均通过后，才可设置：

```dotenv
DELI_EPLUS_ENABLED=true
SHENZHOUHR_DELI_AUTO_SYNC_ENABLED=true
SHENZHOUHR_DELI_AUTO_SYNC_CRON='0 0 * * * ?'
```

凭据只写入受控环境文件或密钥管理器，不得写入本文档、命令参数、日志或版本库。

- [ ] `DELI_EPLUS_APP_KEY`、`DELI_EPLUS_APP_SECRET` 和 credential reference 已由双人核对但未回显。
- [ ] 来源时区为已确认值，默认 `Asia/Shanghai`。
- [ ] cron 精确为 `0 0 * * * ?`，即每天 24 次整点同步。
- [ ] 重启应用使环境变量生效，并确认只存在一个预期调度实例。
- [ ] 首次同步使用默认回看窗口；后续同步从最后成功水位之后增量读取。
- [ ] 成功和失败均写 `deli_sync_log`；失败不推进最后成功水位。
- [ ] 30 天清理任务可运行。
- [ ] 状态只显示时间、记录数、成功/失败和错误信息；没有红黄灯、延迟阈值或月结阻断。
