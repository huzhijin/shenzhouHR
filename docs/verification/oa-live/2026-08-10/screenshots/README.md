# 截图存放说明

本目录用于保存 2026-08-10 OA 实库只读证据原图。

- 文件名使用 `oa-b5-<编号>.png`，例如 `oa-b5-00.png`、`oa-b5-03c.png`。
- 超过一屏时使用 `-p01`、`-p02`；相邻页重复 1 行并保留表头，全部页收齐前状态为 `PARTIAL`。
- 重拍追加版本号，例如 `oa-b5-03c-v2.png`，不要覆盖旧图。
- 入库前确认图片不含密码、连接配置、姓名、工号明文或其他人员明细。
- 只有聊天附件而没有可保存的原始文件时，在
  [`../EVIDENCE.md`](../EVIDENCE.md) 记录收到时间和逐格转录值，不虚构本地图片路径；
  单项只能标为 `TRANSCRIBED_ONLY`。只有取得可持久附件引用或原图文件并记录 SHA-256
  后，才可升级为 `REVIEWED`，仅有转录不能成为 `VERIFIED` 证据。
