# 工时取整、异常去重与查询页导出 — 部署说明

变更：`report-hours-exceptions-export-fixes`（公式目录 `FULL_CALCULATION_OA_HALF_HOUR_V4`）。

## 部署后必须做

1. 发布制品（后端 + 前端）。
2. 对当前 **OPEN** 的公司月执行「重新计算」（或等待得力/OA 定时同步成功后的自动重算）。
3. 抽查：
   - 休息日有加班单且有打卡时，加班小时 > 0，开始/结束为整点或半点；
   - 异常总览同一人同一日同一类型不重复；全天请假不再出缺卡/迟到/早退/旷工；
   - 忘打卡按上班/下班侧计次；
   - 查询页导出能下载 xlsx，失败留在当前页提示；
   - 月度工时/迟到详情抽屉无英文字段，备注列不是第二颗「查看详情」。

未重算的旧 pin 不会被新口径读取（公式版本已提升）。页面会提示核算尚未完成，而不是继续显示加班 0 和重复异常。

## 不要做

- 不要手工 `DELETE FROM attendance_report_exception_fact`。重复行随新 pin 替换。
- 不要自动重开关账/冻结月。关账月若要换新口径，按现有重开规则由 HR 处理。

## 口径摘要

- OA 单据分钟 `< 30` 落到整点，`30–59` 落到半点，已是 `:00`/`:30` 不变。
- 加班认可分钟来自打卡落在取整后加班单内的班外在岗，不再与上班班段求交。
- 月度工时：请假小时不含年假/调休；实际工时 = 应出勤 + 计薪加班 − 事假病假其他 − 年假 + 加班换调休 − 实际调休。
