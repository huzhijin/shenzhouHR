# UI/UX 设计规范

## Visual direction

`product`

用户进入系统是为了完成高密度考勤核对、月结和工资核算，而非浏览品牌展示。视觉方向是“精密制造控制台”：稳定的浅色工作面、清晰的层级线、克制的品牌蓝作为选择/主操作信号，品牌红只用于 Logo、危险操作和关键告警。布局采用熟悉的左导航、顶部全局区、面包屑和任务内容区；无页面入场动画、无渐变装饰、无粒子/3D 地球/持续滚动装饰。

## 1. 设计系统原则

- 所有颜色、字体、间距、圆角、阴影、时长、断点和层级来自 `ui/design-tokens.json`/`.css`；组件禁止 raw hex、一次性 inline style 和 `text-white/bg-white` 等直接颜色工具。
- 每个表面色均有 `on-*` 前景。正文对比度 ≥4.5:1，大字/UI 图形 ≥3:1；已测核心组合见下表。
- 图标只使用 **Tabler Icons**，统一 `2px` stroke、圆端点；不混用图标库、不用 emoji、不手绘装饰 SVG。
- 系统字体栈 `Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`；中文使用系统回退。字号相邻倍率约 1.143，字重只用 400/500/600。
- 组内 8–12px，组间 24–48px；控件圆角 6px、卡片 8px；密度服务任务效率。
- 动效只确认操作或状态变化，100–150ms，仅 `opacity/transform`；不动 `width/height/padding/margin`，支持 `prefers-reduced-motion`。

| `canvas #F6F9FD` / `on-canvas #111827` | 16.80:1 | 通过 |

| `danger-soft #FDEBEC` / `on-danger-soft #8A0010` | 8.75:1 | 通过 |

## 2. 品牌与 Logo 规范

- 品牌名：江苏神州半导体科技股份有限公司。设计参考来自[企业官网](https://www.szsemicon.com/)和[官方 Logo](https://www.szsemicon.com/images/logo.svg)。参考 SVG 的原始 `viewBox` 约为 163.0405×36.87，比例约 4.42:1，主色与当前确认色一致。
- 生产前由企业提供/确认 Logo 授权文件，保存到版本化本地资源目录；运行时不请求官网 URL。设计阶段临时读取物只在 `tmp/prd/logo.svg`，不作为生产资产。
- `BrandConfig` 统一控制 `companyFullName`、`systemName`、`logoAsset`、`faviconAsset`、`loginBackgroundToken`、`primaryToken`、`accentToken`；不允许页面独立覆盖。
- Logo 使用 `object-fit: contain`/等效布局，固定一边、另一边自动；不裁切、拉伸、压缩、变色、滤镜、加阴影或拆分图文。
- 深色导航必须提供白色/浅色承载板展示标准 Logo；没有正式反白版时不自行生成。空间不足只整体缩小。
- PC 登录、PC 导航、移动登录、正式报表页眉使用同一资源；加载失败显示企业全称文本并保留空间，不能显示破图标识。
- 品牌红仅用于 Logo、危险操作、关键告警，不作为大面积背景或普通选中态。

## 3. 信息架构与导航

### PC 一级导航

1. 工作台
2. 组织与人员：组织架构、人员主数据、来源绑定、任职历史
3. 数据接入：同步任务、原始数据、OA 映射、数据冲突
4. 考勤管理：考勤工作台、考勤明细、异常处理、班次规则、月结、年假制度、报表
5. 薪资管理：数据采集、工资项目、工资方案、工资核算、复核发布、补发补扣、工资条管理
6. 权限与审计：角色权限、数据范围、字段权限、授权期限、审计日志
7. 系统运维：配置字典、任务日志、监控告警、备份恢复状态

服务端返回 `menu_key` 和 capability；前端只渲染被授权项，但隐藏不作为安全控制。折叠导航保留图标、tooltip 和当前项；顶部包含全局搜索（受权范围）、任务通知、环境标识、帮助和本人菜单。

### 移动端导航

底部主项最多 4 个：今日、记录、反馈、我的；部门负责人有“团队”入口位于今日工作区。工资条置于“我的”且仅在服务端 capability 存在时出现。层级详情使用返回导航和固定底部操作区，不缩小 PC 表格。

### 大屏导航

默认只读单页；顶部展示范围、统计口径、时间区间、更新时间和全屏按钮。筛选抽屉受服务端数据范围约束，不提供个人工资或个人敏感钻取。

## 4. 角色工作台信息架构

| 角色 | 首屏优先级 | 次级任务 | 禁止/限制 |
|---|---|---|---|
| 老板/最高管理者 | 授权范围聚合趋势、月结/工资进度、风险 | 组织/期间穿透 | 默认不展示个人敏感字段；需显式 PAYROLL 权限 |
| HR 管理员 | 待处理异常、组织变更、数据冲突、月结进度 | 年假制度、人员与规则 | 工资内容仅另授 PAYROLL 后出现 |
| 考勤管理员 | 同步健康、异常队列、待月结范围 | 日明细、规则证据、重跑 | 无工资入口与字段 |
| 薪资经办 | 数据采集校验、输入锁定、运行状态 | 分段差异、公式追溯 | 不能复核/发布自己的运行 |
| 复核/发布者 | 待复核、差异、发布影响范围 | 审计和控制数 | 不修改原始输入 |
| 部门负责人 | 团队考勤概览、待反馈 | 授权团队明细 | 范围外及工资默认拒绝 |
| 普通员工 | 今日考勤、异常反馈、年假、工资条 | 个人月报和制度 | 只能本人；金额默认隐藏 |
| 系统管理员 | 任务、健康、告警、配置 | 权限技术配置、备份状态 | 不因技术角色获得工资/业务明细 |
| 审计/只读 | 高风险事件、权限变更、链完整性 | 受控追溯 | 不执行业务命令 |

### 移动端

今日考勤、打卡记录、请假/加班/外出/出差记录、异常反馈、反馈时间线、年假余额、制度、个人月报、工资条、负责人团队概览。详情均卡片/分组列表化，360–430px 核心功能不横向滚动。

### 数据大屏

1920×1080 基准：在岗概览、出勤趋势、迟到早退、缺勤分布、加班趋势、请假分布、部门对比、同步健康。每图显示单位、区间、口径、更新时间和范围；默认聚合，小组阈值/互补抑制，颜色之外增加标签/线型/图标。

## 6. 核心交互

### 高密表格

表头包含快速筛选、可折叠高级筛选、当前条件 chips、结果数、列设置和受控导出。支持服务端排序、固定关键列、列显隐、游标/分页、批量选择和批量命令。跨页选择必须明确“当前页/全部筛选结果”及影响数。超过屏宽时 PC 工资表允许受控横滚并固定员工/期间列；移动端改为逐项详情，不横滚。

### 穿透

工作台 KPI → 部门 → 员工 → 考勤日 → 原始打卡/OA 单据 → 规则命中 → 结果/调整/月结。每层保留上一级范围 chips、数据版本、更新时间和权限提示；无权层级统一无权限状态，不泄露存在性。

### 高风险确认

删除、月结、重开、重算、工资计算、发布、批量导出展示动作、范围、人数/记录数、规则/输入版本、不可逆影响和审计提示；用户必须输入原因或确认短语（按风险等级），近期登录后提交。按钮在预检完成前禁用。

### 工资揭示

金额初始掩码；“查看金额”调用服务端 `reveal`，近期登录和字段权限通过后取得短时内存数据，页面失焦/超时/退出立即隐藏；不写浏览器持久存储。查看、复制、导出分别是独立 action 和审计事件。

## 7. 组件与页面状态清单

所有核心页面必须对以下 15 种状态提供真实处理；不以假数据、占位图、TODO、空按钮冒充。

| 状态 | 组件行为 | 用户动作/机械验收 |
|---|---|---|
| 首次加载 | 页面骨架保留标题/筛选结构，`aria-busy=true` | 完成后焦点不跳；超时转失败 |
| 局部加载 | 仅刷新表格/卡片，旧数据标“更新中” | 可取消的请求显示取消；重复提交禁用 |
| 空数据 | 说明当前范围/筛选为空 | 提供清除筛选或有权限的创建动作 |
| 无权限 | 统一说明不可访问，不显示对象存在性 | 不展示敏感字段/数量；返回安全入口 |
| 请求失败 | 错误分类+关联 ID | 可重试时提供重试，按钮调用真实请求 |
| 部分同步成功 | 成功/失败范围和水位并列 | 只允许重跑失败范围 |
| 数据冲突 | 冲突字段、来源和影响 | 自动归属停止；进入人工核验 |
| 数据已冻结 | 明确冻结版本/时间/主体 | 编辑禁用；有权者走重开/调整流程 |
| 月结锁定 | 显示范围、状态和阻断 | 不允许直接编辑日结果 |
| 数据已过期 | 显示当前版本和页面版本差异 | 刷新或比较后再提交 |
| 重试中 | 显示次数、下次时间、取消资格 | 状态实时更新且订阅鉴权 |
| 操作成功 | 确认对象和结果，非装饰 toast 唯一反馈 | 焦点回到触发点/新结果 |
| 操作失败 | 保留输入，显示字段/业务错误 | 不泄露堆栈和无权对象存在性 |
| 网络异常 | 区分离线/服务失败，阻止高风险离线排队 | 恢复后用户主动重试 |
| 数据来源不可用 | 已同步数据仍可查，标注新鲜度 | 同步操作显示来源故障，不伪装实时 |

所有控件具备 `hover/focus-visible/active/disabled`；焦点环不依赖颜色单一信号。状态同时使用文字、图标/形状和颜色。

## 8. 响应式规则

| 范围 | 布局规则 | 验收重点 |
|---|---|---|
| ≥1920 | 内容最大宽度可按数据页放宽；大屏 16:9 等比；PC 仍保持工作区密度 | 图表单位/范围可见；无大面积空装饰 |
| 1440×900 | 展开左导航；常用筛选单行+高级筛选 | 表格操作区和分页同屏可达 |
| 1366×768 | 可折叠导航；次级操作收入口令明确的菜单 | 标题、主操作、首屏表格不重叠 |
| 1024–768 | 导航抽屉；双栏变单栏；表格关键列+详情抽屉 | 触控目标 ≥44px；无操作区丢失 |
| 430–360 | 独立移动 IA；卡片/分组列表；底部操作区；安全区适配 | 核心功能无横滚、Logo 比例不变、键盘不遮提交 |

测试视口固定为 1366×768、1440×900、1920×1080、768/1024 平板、360/390/430 手机。大数据表使用服务端分页或虚拟滚动；虚拟表必须保持屏幕阅读器可理解的行数/位置说明。

## 9. 可访问性

- 目标 WCAG 2.2 AA：正文 4.5:1，大字/UI 3:1；焦点可见且不被 sticky 区遮挡。
- 输入有程序化 `<label>`、描述和错误关联；表格表头/排序/选择状态语义化；弹窗/抽屉焦点陷阱和关闭后焦点恢复。
- 键盘可完成筛选、表格行操作、确认、抽屉、工资揭示；危险操作不靠双击/悬停。
- 状态不能只红/绿，使用 Tabler 状态图标、文字和形状；图表提供摘要表或可读标签。
- 点击目标至少 44×44 CSS px（高密 PC 表格的图标按钮可保持视觉 32px，但交互热区 44px且不重叠）。
- 尊重缩放 200%、系统减少动效、系统字体；不锁定横竖屏。

## 10. UI 权限与字段脱敏

| 表面 | 客户端行为 | 服务端硬约束 |
|---|---|---|
| 菜单/路由 | 按 capability 生成，无能力不挂载入口 | 直接请求仍重新鉴权 |
| 列表/搜索 | 只展示返回字段；不缓存敏感结果 | 范围先过滤、字段白名单后序列化 |
| 详情/穿透 | 每层独立加载与无权限状态 | 每个对象独立授权，不继承父列表 |
| 工资金额 | 默认掩码；短时 reveal；不持久化 | 未授权时金额字段不存在；查看审计 |
| 地图 | 无可绘点时展示状态卡 | 坐标对象/字段权限与验证状态同时满足 |
| 附件 | 下载动作单独 capability | 下载时复算对象和字段权限；短时 token |
| 导出 | 显示允许字段/范围和水印预览 | 三阶段复算、字段脱敏、一次性链接、审计 |
| 实时消息 | 仅订阅服务端允许 topic | 建连/订阅/权限变化时复核，payload 最小化 |
| 大屏 | 只呈现授权聚合 | 默认不返回个人工资/成本/个税；小组抑制 |

```json
{
  "companyFullName": "江苏神州半导体科技股份有限公司",
  "systemName": "神州HR考勤与薪资核算系统",
  "logoAsset": "待企业确认后写入本地版本化资源路径",
  "faviconAsset": "待企业确认",

  "accentToken": "color.brand.danger",
  "logoFallback": "江苏神州半导体科技股份有限公司"

```

这是设计契约，不是运行配置文件；正式资产路径必须在 `preview_confirm` 前由企业确认。
