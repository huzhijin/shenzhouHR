# 核心页面线框与交互注释

> 视觉注册：`product`。线框用于冻结信息层级和交互边界，不替代视觉稿；颜色、字体、间距、圆角、状态和动效均由 `ui/design-tokens.*` 提供。

## 1. PC 壳层与 HR 工作台

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Logo / 神州HR    全局搜索       任务通知   环境标识   帮助   本人菜单        │
├──────────────┬───────────────────────────────────────────────────────────────┤
│ 工作台       │ 工作台 / HR 工作台                         数据截至：批次时间 │
│ 组织与人员   ├───────────────────────────────────────────────────────────────┤
│ 数据接入     │ [待处理异常] [同步健康] [月结进度] [工资运行状态（按权限）]   │
│ 考勤管理     ├───────────────────────────────────────────────────────────────┤
│ 薪资管理*    │ 风险与待办                     本月出勤概览                    │
│ 权限与审计   │ ┌─────────────────────────┐  ┌────────────────────────────┐ │
│ 系统运维     │ │ 按影响级别、范围、期限排序│  │ 趋势、口径、范围、更新时间  │ │
│              │ └─────────────────────────┘  └────────────────────────────┘ │
│              │ 同步与计算任务                 数据冲突                        │
│              │ 状态 / 水位 / 重试 / 负责人     来源 / 原因 / 影响 / 处理入口   │
└──────────────┴───────────────────────────────────────────────────────────────┘
```

`*` 菜单由 `GET /api/v1/me/capabilities` 返回；隐藏不替代服务端鉴权。KPI 必须可穿透并保留范围、版本和筛选条件，不展示无来源的业务数字。

## 2. 组织架构与变更同步

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 组织与人员 / 组织架构    [当前投影] [历史版本]       [预览组织架构变更]      │
├───────────────────┬──────────────────────────────────────────────────────────┤
│ 组织树             │ 当前节点：名称 / 编码 / 类型 / 有效期 / 来源状态         │
│ 搜索               ├──────────────────────────────────────────────────────────┤
│ 公司               │ 子组织与岗位表                                            │
│ ├─ 部门            │ 名称 | 编码 | 来源ID | 状态 | 生效时间 | 人员数 | 操作   │
│ └─ 部门            ├──────────────────────────────────────────────────────────┤
│                    │ 右侧抽屉：版本时间轴 / 变更对比 / 来源绑定 / 任职历史     │
└───────────────────┴──────────────────────────────────────────────────────────┘
```

变更预览先显示新增、停用、移动、编码/名称变化、来源 ID 复用疑点和影响人数。存在冲突时正式同步按钮禁用；确认页展示预览摘要哈希、范围、原因和审计说明。

## 3. 人员主数据与来源绑定冲突

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 人员主数据   [状态] [组织] [来源绑定状态] [高级筛选]   [导出（受控）]         │
├──────────────────────────────────────────────────────────────────────────────┤
│ □ 姓名 | OA工号 | 当前组织 | 岗位 | OA绑定 | 得力绑定 | 任职有效期 | 操作     │
│ ──────────────────────────────────────────────────────────────────────────── │
│ 选择行后打开详情抽屉：                                                        │
│ 内部 employee_id（不可变）                                                    │
│ 来源绑定时间线：致远人员ID / OA CODE / 得力 user_id、ext_id、employee_num     │
│ 任职历史：组织 / 岗位 / 工资方案 / 成本中心 / 生效区间                        │
│ 冲突处理：冲突字段、证据、影响范围、候选绑定、确认理由                        │
└──────────────────────────────────────────────────────────────────────────────┘
```

外部 19 位及更长 ID 仅按字符串展示与传输。重复、缺失、变化或冲突时自动归属停止；处理动作只关闭旧绑定并新增绑定，不能覆盖历史。

## 4. 考勤明细与证据链

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 考勤明细  [期间] [组织] [员工] [状态] [高级筛选]       [重算] [受控导出]      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 员工 | 日期 | 班次 | 首末打卡 | OA事实 | 结果 | 异常 | 月结状态 | 操作        │
├──────────────────────────────────────────────────────────────────────────────┤
│ 详情抽屉                                                                    │
│ [原始打卡]—[标准化]—[OA业务单据]—[规则命中]—[计算结果]—[人工调整]—[月结结果] │
│ 每层：来源记录 / 同步批次 / 输入水位 / 规则版本 / 原因码 / 操作审计           │
│ 位置：原始坐标、坐标系、校验/转换状态；仅验证通过时显示地图                   │
└──────────────────────────────────────────────────────────────────────────────┘
```

重新计算为异步命令，提交前显示范围和输入版本。月结冻结后编辑入口禁用，有权用户只能走重开或追加调整流程。

## 5. 月结工作区

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 考勤月结 / 期间与范围                     状态：准备中 / 校验中 / 已关闭       │
├──────────────────────────────────────────────────────────────────────────────┤
│ 预检摘要：覆盖人数 | 未解决异常 | 同步水位 | 规则版本 | 数据冲突 | 审计状态   │
├───────────────────────────────┬──────────────────────────────────────────────┤
│ 阻断项                         │ 月结版本与操作记录                           │
│ 原因 | 影响 | 负责人 | 入口    │ 创建 / 关闭 / 重开 / 重算 / 差异            │
└───────────────────────────────┴──────────────────────────────────────────────┘
```

预检未通过、审计链不可用或输入水位过期时失败关闭。重开必须填写原因并明确影响范围；旧月结版本永久可查。

## 6. 工资运行与分段明细

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 工资核算 / 期间   采集→校验→锁定→计算→复核→发布        [金额显示：隐藏]      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 员工 | 组织 | 分段数 | 应发 | 社保 | 公积金 | 个税 | 实发 | 差异 | 状态      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 分段详情                                                                      │
│ 生效区间 | 部门 | 岗位 | 方案 | 工作日/工时 | 成本中心 | 项目金额 | 公式证据  │
│ 控制数：各分段合计 = 员工期间合计；输入快照 / 政策版本 / 考勤月结版本         │
└──────────────────────────────────────────────────────────────────────────────┘
```

工资金额字段默认不出现在无权限响应中；有权限用户也需执行短时 `reveal`，页面失焦或超时后重新隐藏。经办、复核、发布职责互斥；已发布记录只能通过补发、补扣或冲销新增记录。

├───────────────────┼──────────────────────────────┼───────────────────────────┤
│ 迟到早退趋势       │ 缺勤与请假分布               │ 加班趋势                  │

大屏只返回授权聚合，不展示个人工资、成本、个税或精确位置。颜色之外同时使用标签、线型或图形；加载、空数据、部分同步、失败和过期状态不得用模拟数据填充。

## 9. 通用状态与焦点顺序

所有页面复用 `08-uiux-specification.md` 的 15 类异步/业务状态。焦点顺序固定为跳过导航→页面标题→筛选→主操作→结果→分页/详情；抽屉和对话框关闭后焦点返回触发点。危险动作只有预检成功后可用，`hover`、`focus-visible`、`active`、`disabled` 均由 Token 驱动。
