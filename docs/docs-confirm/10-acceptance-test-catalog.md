# 可执行验收测试目录

> 基线：PRD V1.7、当前明确业务决策及 `02-requirements-traceability.md`。所有测试只使用合成或不可逆脱敏数据；模拟适配器通过不等同于真实集成完成。

## 1. 测试证据规则

每次执行保存：构建版本、环境、用例 ID、输入夹具版本、数据库迁移版本、规则/映射版本、主体与权限摘要、请求关联 ID、实际结果和证据路径。工资与精确位置不得写入普通测试日志；失败截图和响应体也必须脱敏。

通过门：P0 用例全部通过；安全负向用例不得豁免；外部系统、容量、恢复类用例未具备真实环境时保持 `BLOCKED`，不能用 mock 结果改成 `PASS`。
