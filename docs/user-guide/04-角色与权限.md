# 04 角色与权限

## 权限由两部分组成

账号能看到什么，由“角色”和“数据范围”共同决定：

- 角色决定可以使用哪些功能；
- 数据范围决定可以查看或管理哪些公司、组织或员工。

只分配角色但不设置正确范围，可能导致看不到数据或看到过多数据。

## 默认角色说明

| 角色 | 适用人员 | 常用数据范围 |
| --- | --- | --- |
| 系统管理员 | 负责账号、权限和系统管理的少数人员 | 按批准的管理范围 |
| HR 管理员 | 维护组织、员工和考勤配置的 HR 人员 | 公司 |
| 高管 | 查看授权范围内的工作台和报表 | 公司或组织 |
| 部门负责人 | 查看所选部门及允许的下级组织 | 组织 |
| 员工本人 | 查看自己的考勤、假期和反馈 | 本人 |
| 审计只读 | 查询操作记录，不修改业务数据 | 按批准的审计范围 |

系统不再提供“制造中心主管”或“制造中心主任”角色。原本需要此类权限的人员统一使用“部门负责人”，并选择对应组织范围。

同一个角色可以配置多条数据范围。例如，一个部门负责人可以同时负责“江苏神州 / 财务部”和“上海昇州 / 供应链部”；这些范围彼此独立，不要求属于同一家公司。

## 修改已有账号的角色与数据范围

1. 进入“账号管理”，查询并打开目标账号。
2. 找到“角色与数据范围”，先点击“加载角色”。未加载前页面只展示当前授权，不能直接修改。
3. 找到要调整的角色；需要新增一条范围时，点击该角色下的“新增授权范围”。
4. 按角色选择数据范围：本人、部门或公司。
5. 配置部门范围时，先选“组织所属公司”，再从该公司的组织树中选择“部门”，避免误选其他公司的同名部门。
6. 部门范围默认只授权所选部门本身；确实需要查看整个子树时，再主动勾选“包含下级部门”。每一条范围的开关相互独立。
7. 修改已有公司或部门时，直接在该条范围内重新选择；不再需要的范围点击“移除此范围”。
8. 需要管理多个公司或部门时，逐条点击“新增授权范围”，不要通过扩大到整家公司代替精确授权。
9. 如为临时授权，填写授权生效时间和授权到期时间；长期有效时到期时间可以留空。
10. 点击“保存授权”，再重新打开账号详情，逐条核对公司、部门、是否包含下级部门和有效期。

新建账号时不用先保存再进入详情：在“创建本地账号”窗口选择角色后，点击“添加范围”即可增加同一角色的第二条范围；“删除”用于删除尚未保存的范围。

授权应由有权管理该范围的管理员操作。系统拒绝越权授权时，不要通过扩大自己的权限绕过。

## 部门负责人能看到什么

部门负责人通常只能查看：

- 被授权组织中的当前在职员工；
- 勾选“包含下级部门”时，该组织的下级组织及员工；
- 其他公司中另外明确授权的部门及员工；
- 上述范围内的考勤工作台和报表。

部门负责人不等同于 HR 管理员，不能因为负责某个部门就自动获得全公司人员维护或系统配置权限。

### 跨公司负责多个部门

以“江苏神州 / 制造部”和“上海昇州 / 质量部”为例：

1. 为账号添加“部门负责人”角色。
2. 第一条范围选择“江苏神州”，再选择“制造部”，按需设置是否包含下级部门。
3. 修改已有账号时点击“新增授权范围”；创建新账号时点击“添加范围”。
4. 第二条范围选择“上海昇州”，再选择“质量部”，按需设置是否包含下级部门。
5. 保存并重新登录验证。

系统会把多条有效范围合并后用于人员列表、考勤工作台和报表查询。未明确勾选的公司或部门不会因为角色名称相同而自动可见。

## 高管的数据范围

- 首次为账号选择“高管”角色时，系统默认加入当前管理员有权授予的全部启用公司，便于一次完成初始化。
- 默认值可以在保存前删除或补充；保存后也可以随时按实际职责调整。
- 后续新增公司不会自动加入既有高管账号。公司上线后，由管理员打开账号详情，手工增加该公司范围并保存。
- 高管也可以不用整家公司范围，而改为一条或多条精确的组织范围。
- “高管”本身不等于不受限制的全集团权限；所有看板、报表和导出均以后端保存的有效数据范围为准。

如果账号需要导出报表，还必须具有对应的导出功能权限；仅能查看报表不代表可以导出。

## 最小授权原则

- 普通员工只分配“员工本人”。
- 部门管理人员优先分配“部门负责人”，不要直接给 HR 管理员。
- 只需查看操作记录的人员使用“审计只读”。
- 系统管理员数量应尽量少，并定期复核。
- 工作职责变化、调岗或离职后，应立即调整或结束授权。

## 授权后验证

建议使用不含真实业务数据的测试方法验证：

1. 让目标用户重新登录；
2. 确认菜单与职责一致；
3. 分别切换或筛选每个已授权公司，确认只能看到勾选的公司或组织；
4. 确认不能修改职责之外的数据；
5. 使用一个未授权公司或部门做反向验证，确认列表、报表、看板和导出均不会返回其数据；
6. 在“操作记录”中核对授权变更留痕。
