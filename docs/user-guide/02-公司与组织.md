# 02 公司与组织

## 公司和组织有什么区别

- 公司：用于隔离人员、权限、考勤配置和报表数据。
- 组织：公司内部的部门、中心、车间或团队，可以有多层上下级关系。

一个公司可以包含多个一级组织。一级组织的数量不能用于判断系统中有几家公司，也不能据此自动生成公司记录。是否属于独立公司，应以正式公司资料和最终确认的数据方案为准。

本次导入源文件中，620 行人员的“所在组织机构”全部是“江苏神州半导体科技股份有限公司”；“上海晟州聚能半导体科技有限公司”“上海昇州半导体科技有限公司”和“江苏芯越半导体科技有限公司”出现在“所属部门”的一级路径中。因此当前系统按 1 个数据所属公司、4 个一级组织保留，页面只显示 1 个可切换公司是与源文件一致的结果。若这 3 个一级组织需要升级为独立公司，必须先补充正式公司编码、数据边界、人员归属及权限方案，再执行迁移，不能只按名称自动拆分。

## 选择当前公司

1. 查看页面顶部或表单中的“公司”。
2. 只有一家授权公司时，系统自动选中。
3. 有多家授权公司时，选择本次要管理的公司。
4. 确认公司全称无误后，再维护组织或员工。

公司选项可附带公司代码用于区分，但应以中文公司全称为主要识别信息。

## 查看组织树

进入“部门与组织”页面后，从左到右或从上到下查看组织层级。建议重点核对：

- 每个组织的名称和编码；
- 上级组织是否正确；
- 部门、中心、团队之间的层级是否正确；
- 是否存在同名但实际不同的组织；
- 已停用组织是否仍被用于新任职或新授权。

## 新增组织

1. 进入“部门与组织”。
2. 选择正确的当前公司。
3. 点击新增组织入口。
4. 填写组织名称、编码、类型和生效日期。
5. 选择上级组织；创建根组织时按页面要求留空或选择公司根节点。
6. 填写简明的变更原因。
7. 保存后，在组织树中核对位置。

不要仅凭名称判断上级组织，提交前应同时核对完整层级路径。

## 调整组织

修改名称、上级组织或状态前，应先确认：

- 是否会影响员工当前任职；
- 是否会影响部门负责人权限范围；
- 是否会影响考勤组或报表筛选；
- 生效日期是否符合实际业务日期。

系统保留历史记录时，应通过页面提供的调整操作新增生效版本，不要试图删除历史数据。

## 停用组织

停用前先处理该组织下的在职员工和仍有效的权限。建议顺序为：

1. 将员工调整到新的任职组织；
2. 调整部门负责人等组织范围权限；
3. 检查该组织是否仍被考勤或报表使用；
4. 最后停用组织。

## 完成后的核对

- 组织树没有断层或循环；
- 员工所在部门与实际一致；
- 部门负责人只能看到授权组织及允许的下级组织；
- 切换公司后不会看到其他公司的组织和员工。
