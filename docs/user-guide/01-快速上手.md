# 01 快速上手

## 登录系统

1. 打开系统登录页。
2. 输入管理员提供的登录名和临时密码。
3. 点击“登录”。
4. 首次登录时，按页面提示设置新密码后重新登录。

系统不会在本手册中提供任何默认账号或密码。忘记密码时，请联系有账号管理权限的管理员重置。

## 首次登录必须改密

每个新账号都有独立的临时密码。首次登录只能先修改密码，完成后才能进入业务页面。

设置新密码时：

- 按页面显示的长度和复杂度要求填写；
- 不要使用工号、姓名、公司简称或容易猜到的连续字符；
- 不要与他人共用密码；
- 不要把密码粘贴到群聊、工单或操作截图中。

## 选择管理公司

- 当前账号只管理一家公司时，系统会自动选中该公司，无需重复选择。
- 当前账号可管理多家公司时，先在公司选择器中明确选择，再进行后续操作。
- 公司列表只展示当前账号有权管理的正式公司；测试、验证用公司不会显示。
- 切换公司后，重新核对页面标题和筛选条件，再新增、导入或修改数据。

如果页面显示的公司不正确，请先停止操作并查看[常见问题](07-常见问题.md)，不要把数据录入到其他公司。

## 认识页面

管理员常用功能包括：

- 组织与人员：部门与组织、员工、导入人员；
- 考勤设置：班次、工作日历、考勤组、考勤规则；
- 数据接入：考勤机数据、OA 单据和同步记录；“导入打卡文件”当前只开放模板及历史任务查询，正式上传、预检和发布尚未开放；
- 系统管理：账号管理、角色权限、操作记录；
- 业务查看：考勤工作台、考勤报表。

实际菜单会按照权限自动精简，因此不同账号看到的菜单可能不同。

## 安全退出

完成工作后，点击页面右上角“退出”。在公共电脑或临时设备上使用系统后，还应关闭浏览器窗口。

## 第一次使用建议检查

进入系统后依次确认：

1. 当前公司正确；
2. 组织树层级正确；
3. 员工数量和任职部门正确；
4. 需要登录的员工已开通账号；
5. 全集团共享地点目录只有扬州、成都、大连、上海、合肥、武汉、深圳 7 条，各公司默认考勤组选择扬州；
6. 默认考勤组及人员归属完整；
7. 班次、工作日历和考勤规则已经发布并处于正确生效期。
