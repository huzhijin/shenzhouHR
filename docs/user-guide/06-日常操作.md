# 06 日常操作

## 每日建议顺序

1. 确认当前公司和业务日期。
2. 检查考勤来源或导入任务是否成功。
3. 查看考勤工作台中的人员数量和异常数量。
4. 处理缺卡、迟到、请假或来源冲突等异常。
5. 抽查报表，确认结果与原始依据一致。

## 在线考勤与 OA 数据

进入“考勤机数据”或“OA 单据”后，先核对来源状态和最近同步时间。需要手动同步时：

1. 确认当前公司和数据时间范围；
2. 发起同步；
3. 可离开页面，稍后到“同步记录”查看结果；
4. 失败时查看中文错误说明和关联编号，再决定重试或联系管理员。

不要在上一次同步仍处理中时反复提交相同任务。

## 导入打卡文件

进入“导入打卡文件”：

1. 选择正确来源和公司；
2. 按模板准备文件；
3. 上传后先运行检查；
4. 核对时间、人员匹配和重复记录；
5. 修正阻断错误后再确认导入；
6. 在导入详情中保存成功数量、失败数量和错误报告。

同一文件重复提交时，应先确认系统是否已识别为重复任务，避免人为修改文件名后再次导入相同数据。

## 查看考勤工作台

工作台用于快速判断数据是否完整。建议重点查看：

- 应出勤人数与已产生结果人数；
- 迟到、早退、缺卡等异常数量；
- 是否存在整个部门或考勤组没有结果；
- 数据日期和更新时间是否符合预期。

工作台数字异常时，先检查数据来源、人员考勤组归属和工作日历，不要直接修改报表结果。

## 查询和导出报表

进入“考勤报表”后：

1. 选择公司、组织和日期范围；
2. 点击查询；
3. 核对汇总数量和异常项；
4. 需要留档时再导出；
5. 导出文件按公司敏感数据要求保存和传递。

部门负责人只能查看已授权组织及允许的下级组织；看不到其他部门属于正常权限控制。

## 调整规则或班次

规则、班次、日历和考勤组的调整都应填写明确的生效日期和原因。建议：

1. 新建后续生效版本；
2. 完成校验；
3. 查看影响范围；
4. 发布；
5. 用一名非敏感样例员工和一个样例日期验证；
6. 在“操作记录”中核对留痕。

不要为了修正未来配置而覆盖已经用于历史核算的版本。

## 员工入职、调岗和离职

- 入职：创建员工和任职，按需要开通账号，并分配考勤组。
- 调岗：新增或调整任职，检查部门负责人权限和考勤组是否需要变化。
- 离职：结束任职、终止考勤组归属并锁定账号。
- 二次入职：使用二次入职流程新增任职记录，不要重复创建员工。

## 操作完成后

每次批量导入、权限调整或规则发布后，至少核对一次：状态、数量、生效日期、适用范围和操作记录。
