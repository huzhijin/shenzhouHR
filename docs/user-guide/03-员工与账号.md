# 03 员工与账号

## 员工与账号不是同一条数据

- 员工档案保存工号、姓名、任职部门和在职状态。
- 登录账号保存登录名、角色、数据范围和登录状态。
- 员工可以暂时没有账号；一个员工不能重复绑定多个本地账号。

建议先完成员工和任职导入，再从员工批量开通账号。

## 通过 Excel 导入员工

进入“导入人员”后，按页面步骤操作：

1. 选择当前公司和导入类型。
2. 下载对应模板，不要自行增加、删除或合并必填列。
3. 创建导入任务并上传 `.xlsx` 文件。
4. 核对字段映射。
5. 点击“运行预检”。预检只生成新增、修改、冲突和错误结果，不会立即写入正式数据。
6. 下载错误行报告并修正阻断问题。
7. 重新上传和预检，直到没有阻断错误。
8. 核对新增、修改和不变数量后，点击“确认发布”。

组织、员工和任职有依赖关系时，建议依次导入：组织 → 员工 → 任职。姓名或部门名称可能重复，员工应以工号等稳定编号匹配。

这里的 `.xlsx` 只用于导入员工资料。当前账号开通不接收 Excel 文件，而是直接从已导入员工中选择；账号开通完成后下载的 CSV 只用于交付本次临时凭据。

## 单个维护员工

进入“员工”后，可以按姓名、工号和状态查询员工。新增或修改时重点核对：

- 工号是否唯一且与正式人事资料一致；
- 姓名是否准确；
- 当前任职部门和入职日期是否正确；
- 离职、调岗或二次入职是否通过对应业务操作办理。

不要为同一自然人重复新建员工档案。

## 从员工批量开通账号

本轮版本使用员工数据直接开通账号，避免再次录入姓名和工号。

1. 进入“账号管理”。
2. 点击“从员工批量开通”。
3. 在弹窗中选择要开通账号的公司；只有一个可管理公司时会自动选中且不可误切。
4. 筛选并勾选需要登录、尚未开通账号的在职员工。
5. 查看预检结果：
   - 登录名默认使用工号；
   - 页面按所选公司显示工号、姓名和当前部门供核对；
   - 已有账号会明确标记，不会重复创建；
   - 工号已被其他账号使用时会明确标记为冲突；
   - 无当前任职、已离职或超出权限范围的员工不会出现在候选列表；找不到员工时先核对员工状态、当前任职和管理员权限。
6. 勾选不超过 20 人后点击“开通已选”，或点击“开通全部”检查当前公司、当前查询条件下所有分页中的可开通员工。确认弹窗显示的人数才是最终影响范围，提交前必须再次核对。
7. 系统每批最多创建 20 人。“开通全部”会分批处理；如果后续批次失败，前面已经成功的账号不会回滚。先保存成功部分的临时凭据 CSV，再刷新预检并只处理剩余人员。
8. 如果网络中断导致系统无法确认某一批是否已经写入，窗口会在内存中保留本批次的请求标识和随机恢复键，并显示“重新确认上次批次”。点击后系统会确认同一批员工；若账号已经创建，会返回与首次请求完全相同且仍有效的临时密码，不会重复建号或再次换密。确认完成前不要关闭或刷新窗口，也不要重新选择员工。
9. 系统完成后会自动下载本次成功账号的临时凭据 CSV；窗口未关闭前可再次下载。该文件是未加密的敏感明文文件，保存到磁盘后不会自动失效或删除，确认下载成功后再关闭窗口，并在交付完成后人工安全删除。

批量开通只创建登录账号，不会修改员工档案或任职部门。

## 初始密码如何处理

- 系统为每个新账号生成不同的临时密码，不使用全员相同密码。
- 临时密码仅随本次成功响应进入浏览器内存并生成 CSV；不在账号列表展示，不以明文写入数据库或操作记录，也不写入浏览器持久存储。
- 同一批次因网络异常重放时，系统会在 1 小时安全窗口内确认并返回同一组临时密码，不会重复建号或反复换密。只有账号仍为“员工本人/本人范围”、从未登录且凭据未被修改时才允许确认。
- 随机恢复键只保存在当前窗口内，不写入浏览器持久存储。关闭或刷新窗口、超过恢复窗口、账号权限或密码已变化后，不能再用原批次取回临时密码；清单遗失时只能进入账号详情设置新的临时密码。
- 下载后应尽快通过安全渠道分别交给员工，不要把整份文件发到群聊。
- 员工首次登录必须修改密码。
- 临时密码文件交付完成后应立即安全删除。只有公司已有正式的凭据托管制度时，才允许加密、限权并限期留存。

## 单个创建账号

只有员工记录暂时无法使用或需要创建非员工功能账号时，才使用“单个创建账号”。填写时应核对显示名称、绑定员工、角色及数据范围。

普通员工账号优先通过“从员工批量开通”创建，避免手工输入错误。

单个创建页面可以直接添加多条“角色＋数据范围”，不必创建后再补录。部门负责人需要跨公司负责多个部门时，每条都先选公司，再选该公司下的部门，并分别决定是否“包含下级部门”。组织范围默认只授权所选部门，需要查看下级时再主动勾选。首次选择“高管”角色时，系统会加入当前可授权的全部启用公司，保存前仍可删减。

## 账号日常管理

在“账号管理”中可以查询账号状态并进入详情。常见操作包括：

- 重置密码：由管理员设置新的强临时密码，用户下次登录时修改；
- 锁定账号：立即阻止继续登录；
- 解锁账号：确认风险消除后恢复登录；
- 调整角色：按工作职责和数据范围授权；
- 撤销会话：让已登录设备重新验证身份。

员工离职后，应及时终止任职并锁定账号；不要只依赖人员名单更新。
