# 神州 HR V1.9 规格确认摘要

## 1. 产品边界

V1.9 首发目标是建立独立人事底座与可解释、可追溯、可重算、可月结的考勤闭环。考勤 P0-A 不被薪资复杂度阻塞；薪资仅作 P0-B 后端预留且当前前端完全不可发现。

## 2. 已确认业务决策

### 登录、组织与人员

- 管理端和员工端使用本系统独立账号密码，不依赖 OA SSO。
- 账号覆盖创建、临时密码、首次改密、失败锁定、重置、停用、session 失效、退出、权限和审计。
- 致远组织仅通过 Excel 做期初导入；发布后由神州 HR 独立维护。
- 本期没有组织定时、手动持续、双向或“组织架构变更同步”。
- OA 请假、加班、外出、出差、补卡仍以只读业务单据接入。
- 二次入职新建任职周期，历史不覆盖；入职前累计工龄维护和导入全审计。

### 统一规则

- 规则使用受控类型和枚举，不允许任意脚本。
- 统一支持模板、版本、草稿、校验、发布、停用、回滚、作用范围、生效期、优先级、冲突、影响预览和样例试算。
- 个人特殊情况通过有期限专用组处理，不写个人/城市硬编码。
- 冻结期间引用快照；重开和重算生成新版本及差异。

### 考勤设置与计算

- 夏冬令由同一考勤组的班次版本和生效期表达。
- 所有考勤组默认启用晚餐扣除；加班餐扣默认适用所有班组。
- 迟到宽限默认自然月 1 次，`0 < late <= 15 分钟`，超过 15 分钟不消费，跨组不重置。
- 单边缺卡默认 7 自然日待补正；逾期仅对应工作段旷工。
- 请假、外出、补卡、出差、加班统一进入证据链，按优先级和时间边界切分。
- 原始事实不改写；计算、调整、重算和月结均版本化。

### 假别、年假与时间账户

- 所有假别版本化配置，默认按工作日。
- 年假资格与档位分离：
  - 最新任职周期本公司连续满 12 个完整日历月取得资格；
  - 累计工龄决定 5/10/15 天，即 40/80/120 小时。
- 最新入职周年日发放，至下一周年日前一天；周期内跨档默认下一周年生效；二次入职重置资格/周年。
- 任职统一 `[start_date,end_exclusive)`；2 月 29 日默认在非闰年 2 月 28 日周年。周年日先失效旧周期再发新 grant；离职、再入职、规则切换和冻结重开均有单独命名测试。
- 工时、调休、年假期初余额通过 Excel 导入；余额只由不可变流水汇总。

### 离线/异构考勤打卡 Excel

- 只导入设备原始打卡事实，不能导入迟到、旷工或加班结果，也不能绕过补签。
- 得力 API、设备 Excel 和 OA 单据统一进入：

  `原始事实 → 标准化/匹配 → 有效事件 → 考勤计算`

- 标准 `.xlsx` 模板已交付；不同厂商通过保存并版本化的 mapping profile 兼容。
- 文件 hash 幂等；原始记录 ID 优先，否则稳定指纹；API/Excel 精确重复合并为一个 effective event；近 60 秒疑似重复待裁决，裁决前不进入计算，全部 raw fact 始终保留。
- 默认 20MB、50,000 行、`Asia/Shanghai`、近似重复 60 秒、严格发布。
- 冻结/月结期间可上传预检，默认不可发布；重开后才允许发布/重算并保留差异。
- 上传、预检、发布、部分发布、作废/冲正、原文件/行、错误报告和重算分别鉴权。

### 薪资边界

- P0-B 不阻塞 P0-A。
- 默认 feature flag 关闭；无菜单、route、首页卡片、搜索、通知、导出、员工入口或埋点。
- 后端 `PAYROLL` 独立域默认拒绝，通用 DTO 不返回工资字段。
- 若后续授权，只读冻结考勤快照；本期无工资条、税社保默认值或银行付款文件。

## 3. 工程基线

保留 React 19、TypeScript、Vite、Ant Design、Tabler Icons、Java 21、Spring Boot、MyBatis、Flyway、权限/数据范围、审计表、关联 ID、AppShell、设计 Token、演示模式和部署模板。

当前实际实现仅有：

- 前端 `/organization`、`/employees`；
- 后端 3 条只读 GET；
- Flyway V1/V2；
- 基础权限/数据范围与有限测试。

其余 V1.9 功能均是待实现规格，不能用 Open Design 或演示模式冒充。

## 4. 领域与契约方向

- 模块化单体、单向依赖。
- 组织/规则/来源/计算/时间账户全部显式版本和快照。
- 文件、批次、行、raw fact、effective event、calculation version、close snapshot 和审计可追踪。
- API 使用统一认证、错误、关联 ID、幂等、并发版本和文件安全合同。
- V1/V2 不改，从 V3 起逐波增量迁移。

## 5. UI/UX 方向

- Register：`product`。
- 本目录 `design-tokens.json/css` 是同构的 canonical candidate；人工 `docs_confirm` 后生效，实施时只使用语义 token。
- 唯一图标库 Tabler Icons、2px stroke。
- 所有交互有 hover/focus/active/disabled；所有异步页有 loading/empty/error/401-session-expired/403，按业务补 conflict/frozen/partial/success；重新鉴权前不闪现旧权限范围数据。
- 静态 HTML/JS 不复制进 React；route、demo ID、月份全部生产参数化。
- Open Design 当前 `VISUAL_CAPTURE_NOT_AVAILABLE`，后续真实浏览器验收不可跳过。

## 6. 实施与停止规则

人工确认本包后，下一次只可授权波次 1。每波完成契约、迁移、后端、权限、前端、自动化测试、说明和真实构建后停止。未实际运行的验证继续标记 `NOT_VERIFIED`。
