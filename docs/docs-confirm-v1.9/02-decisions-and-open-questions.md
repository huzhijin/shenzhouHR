# V1.9 决策与待确认项

## 1. 已确认且不得重复提问

1. 本地账号密码，不依赖 OA SSO。
2. OA 组织仅期初 Excel；发布后本地维护，不做任何持续组织同步。
3. 组织取消同步不影响 OA 考勤业务单据只读接入。
4. 规则类型化、版本化、范围化、可试算；禁止脚本和个人硬编码。
5. 夏冬令是班次版本；所有组默认晚餐扣除。
6. 迟到宽限、单边缺卡、加班餐扣按本轮默认值并可配置。
7. 假别默认工作日；年假资格/档位分离、周年发放/失效、二次入职重置。
8. 时间账户用不可变流水，支持期初余额 Excel。
9. 离线考勤 Excel 导入原始事实，跨来源幂等/去重并受月结保护。
10. 薪资前端完全不可发现，PAYROLL 独立默认拒绝。
